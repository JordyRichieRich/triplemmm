# TripleMMM — Myco Muse Mantra

A static, responsive first-pass homepage for GitHub Pages.

## Publish with GitHub Pages
1. Upload `index.html`, `styles.css`, and `script.js` to the **root** of your `triplemmm` repository.
2. Open the repository on GitHub and select **Settings**.
3. In the left sidebar, choose **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes and refresh the Pages settings to find your published URL.

## Before public launch
- Replace the sample email address `hello@triplemmm.com` with a real contact address.
- Connect the collection cards to real collection pages / approved product links.
- Confirm every product and checkout provider is allowed for your catalog and location.
- Replace remote Unsplash imagery with brand-approved images if desired. The photos and Google Fonts load from third-party services.
- Add accurate privacy, returns, shipping, accessibility, and contact information where relevant.
- This is a front-end homepage only; it does not include cart, inventory, order processing, or payment handling.
