# TripleMMM image-rich homepage

This ZIP contains a new static homepage design with cannabis and mycology imagery. It does not change your GitHub repository until you upload the files.

## Before uploading
- The sample homepage uses remote image URLs. If a host changes its URL or blocks requests, an image may stop appearing.
- Image licenses vary. Check the individual file page and add required attribution before commercial use:
  - Cannabis trichomes: https://commons.wikimedia.org/wiki/File:Cannabis_Trichomes_(17300377912).jpg
  - Mycelium: https://commons.wikimedia.org/wiki/File:Mycelium_(mushroom).jpg (marked CC BY 4.0; attribution required)
  - Oyster mushroom mycelium: https://commons.wikimedia.org/wiki/File:Oyster_mushroom_(Pleurotus_ostreatus)_mycelium_on_coffee_grounds.JPG
- `hello@triplemmm.com` is a placeholder. Replace it with your actual contact email.
- This is not an online store and does not include checkout or payments.

## Upload steps
1. Download and unzip this package on your computer.
2. Open https://github.com/JordyRichieRich/triplemmm
3. Safest: download a backup of your current repo before replacing anything.
4. Click **Add file → Upload files**.
5. Upload `index.html`, `styles.css`, and `script.js` from the unzipped folder to the repository root. Confirm replacement only if you want this new homepage.
6. Commit the changes to `main`.
7. Visit https://jordyrichierich.github.io/triplemmm/ and refresh after a few minutes.

If you prefer to keep the existing homepage intact, don't replace `index.html`; we can merge the image sections into your current code instead.
